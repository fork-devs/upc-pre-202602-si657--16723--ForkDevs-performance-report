# ForkDevs - Performance Report (DriveOS)

Bienvenido al repositorio del **Informe de Desempeño y Especificaciones del Proyecto DriveOS** desarrollado por el equipo **ForkDevs** para el curso de **Fundamentos de Arquitectura de Software (SI657 - Sección 16723)** en la Universidad Peruana de Ciencias Aplicadas (UPC).

---

## 🚀 Estructura del Repositorio

El proyecto se encuentra organizado en los siguientes módulos y carpetas principales:

```text
.
├── assets/                 # Recursos visuales e imágenes compartidas por los informes
├── markdown/               # Informe completo en formato Markdown estándar (GFM)
├── typst/                  # Informe en formato Typst (usado para la generación del PDF final)
└── README.md               # Documento de bienvenida e índice principal
```

### 📁 Módulos

- **[`typst/`](./typst/)**: Contiene la versión fuente en lenguaje Typst con sus plantillas (`template.typ`, `header.typ`) para la generación de documentos PDF formateados profesionalmente.
- **[`markdown/`](./markdown/)**: Contiene la versión portable del informe traducida a Markdown puro para su lectura rápida en GitHub o cualquier visor de Markdown.
- **[`assets/`](./assets/)**: Carpeta centralizada de imágenes y diagramas utilizados tanto en el reporte Typst como en el reporte Markdown.
